# nylon for Mac

Runs your [nylon](https://github.com/encodeous/nylon) networks on your Mac.

For macOS 14 or later.

## Install

1. Open `nylon.dmg` and drag nylon onto Applications.
2. Open nylon. If macOS says it can't check the app, go to System Settings → Privacy & Security and click Open Anyway.
